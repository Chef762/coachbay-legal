# Coachbay – Rechtliches

Öffentliche Rechtstexte der App Coachbay (Datenschutzerklärung, Nutzungsbedingungen mit Widerrufsbelehrung, Impressum, Kontolöschung).
Die Texte werden im App-Projekt aus `www/js/legal.js` erzeugt (`node build/gen_privacy.js` → Ordner `site/`) und hierher kopiert.
Hauptadresse ist https://coachbay.de (vom Coachbay-Server ausgeliefert); diese Seiten dienen als Spiegel unter GitHub Pages.
